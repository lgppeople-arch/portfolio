# 메모리 사이클 시나리오 가치평가: 모형 메모

`tools/mem-scenario.html`과 `assets/engines/memscen.js`의 설계 기록입니다. 이 저장소에서 작업하는 다른 세션(Claude Code 포함)이 맥락 없이도 고치고 갱신할 수 있도록 남깁니다. 기준일은 2026-11-20입니다.

## 1. 한 줄 요약

변수 8개를 각각 1~5단계로 고르면(5^8 = 390,625개 조합), 수급 갭 → 시장가격 → 장기공급계약(LTA) → 실현가격 → 매출·영업이익 → 잔여이익모델(RI) 적정주가가 계산됩니다. 회사는 SK하이닉스(`skh`)와 삼성전자(`sec`)입니다.

중심 조합 `33322333`에 업황 확률 [9, 28, 34, 21, 8]%를 가중하면 SK하이닉스 약 120.0만원(현재가 111.2만원 대비 +8%), 삼성전자 약 21.4만원(18.75만원 대비 +14%)입니다. LTA를 끄면(7번 변수 5단계) 각각 약 104.4만원, 17.8만원입니다.

## 2. 계산 순서 (엔진 `evaluate(coKey, lv, opt)`)

| 단계 | 식 | 설명 |
|---|---|---|
| ① 갭 | G = −ln(P_업황)/k + D·노출도·(1 − 흡수[업황]) + 중국 갭 + 무역 갭 | %p, 4Q26 대비 누적. 양수 = 공급과잉 |
| ② 시장가격 | P_m = exp(−k·G_시장), G_시장 = G − L·0.5·max(G,0) + 0.6·전년 흡수분 | k = 7.3929(과잉) / 8.5396(부족) |
| ③ 계약가격 | 상승기: 시장가(하이닉스), min(시장가, 1.10)(삼성) / 하락기: φ·max(계단가, 하한) + (1−φ)·계단가, 계단가 = max(P_m, 전년 계약가·0.66) | |
| ④ 실현가격 | P = L·계약가 + (1−L)·P_m, L = 커버리지 × 이행률 | |
| ⑤ 손익 | 매출 = 4Q26 연환산 × P × Q × 환율/1,335 × 관세계수. 원가 = base·Q·1.10·0.88^(t+1) + 감가상각. 영업이익 = (매출 − 원가 + 몰수 선급금 20%) × (1 − 성과급 10%) + 메모리 외(삼성) | |
| ⑥ 가치 | V = BPS₀ + Σ RI_t/(1+COE)^t + RI₃·ω/(1+COE−ω)/(1+COE)³, ω = 0.6 | |

## 3. 변수 8개 (`VARS`, 0-based 단계)

| # | id | 이름 | 1 → 5 | 주된 경로 |
|---|---|---|---|---|
| 1 | mkt | 메모리 업황 | 초호황 → 침체 | P·Q 경로(`MARKET`) |
| 2 | rate | 금리 | 인하 전환 → 긴축 충격 | COE −0.5 ~ +1.5%p |
| 3 | fx | 원/달러 | 1,450 → 1,250원 | 매출 환산 |
| 4 | trade | 무역분쟁·관세 | 완화 → 휴전 붕괴 | 관세계수, 출하, 업계 갭 |
| 5 | cxmt | 중국 CXMT 증설 | 제재·지연 → 물량 공세 | 갭 −0.5 ~ +4.0%p (2027년 25%만) |
| 6 | ai | AI 수요 충격(젠슨 황 사태 등) | 충격 없음 → 심각 | 수요 손실 0~15%, 하이닉스 COE 가산 |
| 7 | lta | 장기공급계약 | 강함 → 무력화 | 커버리지, 하한, φ, 이행률 |
| 8 | val | 밸류업·수급 | 재평가 → 디스카운트 확대 | COE −1.0 ~ +1.0%p |

중심 조합 `CENTRAL = [2,2,2,1,1,2,2,2]`, 즉 코드 `33322333`입니다.

## 4. 출발점과 출처

- 2026년 3분기 실적: SK하이닉스 매출 104.6조원, 영업이익 83.3조원. 삼성전자 DS 매출 147.1조원, 영업이익 106.5조원.
- 2026E BPS: 하이닉스 488,978원, 삼성 106,052원(메리츠증권 2026.11.6). 현재가는 2026.11.20 장중 값입니다.
- 2027 컨센서스(에프엔가이드): 하이닉스 약 404조원, 삼성 약 545조원. 업황 2단계·수요 충격 없음이 ±10% 안에 들도록 맞췄습니다(검산 항목).
- k: Micron 10-K의 회계연도 D램 ASP 변화와 TrendForce 수급 갭으로 보정했습니다. 2006~2026 백테스트의 연간 방향 적중은 3/7로 예측력이 낮습니다. 이 식은 "갭이 주어졌을 때의 환산기"로만 쓰십시오.
- LTA: 하이닉스는 14개 고객·2027~28 생산능력 50% 이상, 삼성은 생산능력 60~70%·롤링 5년입니다. 일부 계약은 하한이 현재가의 80%이고, 선급금은 10~30%입니다(2026년 7~11월 보도).

## 5. 갱신하는 법

1. **분기 실적이 나오면** `CO.skh/sec`의 `exit`, `op26`, `bps0`, `price`를 고친 뒤 `node assets/checks.js`를 돌립니다. 컨센서스 검산이 깨지면 `MARKET.P` 2단계를 다시 맞춥니다.
2. **새 변수를 넣으면** `VARS`에 5단계를 추가합니다. `NV`, `TOTAL`, 페이지 문구(390,625), 해시 정규식 `[1-5]{8}`, `README`, 검산의 `M.TOTAL === 390625`를 함께 고쳐야 합니다.
3. **페이지를 더하거나 빼면** `scripts/site-map.json`을 고치고 `python3 scripts/build-site.py`를 돌린 다음, `make-og.js`와 `export-pdf.js` 목록을 고치고 `node scripts/check-site.js`를 돌립니다.

## 6. 한계

- 단계별 수치(하한, 이행률, 수요 손실, 할인율 가감)는 보도에 근거한 가정이지 추정치가 아닙니다.
- 메모리 외 사업(삼성의 MX·VD·파운드리 등)은 단계별 고정값으로 단순화했고, 우선주는 보통주와 같은 값으로 셌습니다.
- 변수는 서로 독립으로 고르게 했습니다. 실제로는 금리와 환율, 무역분쟁과 AI 수요가 함께 움직입니다. "같은 무게" 분포는 이 상관을 무시하므로 극단 조합이 과대 대표됩니다.
- 교육용 모형이며 투자 권유가 아닙니다.
