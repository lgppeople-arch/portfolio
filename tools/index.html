도구·리포트 모음

이 포트폴리오의 실무 도구 15개, 분석 리포트 6편, 분석·보고 노트 5편을 한곳에 모았습니다. 분야를 고르거나 찾는 말을 넣으면 맞는 것만 남습니다. 도구의 예시 수치는 모두 가상이고, 기업 분석 리포트는 공시 원문 숫자만 썼습니다.

읽는 경로 다섯 가지

어디서부터 볼지 고민된다면 관심 있는 일의 흐름을 하나 골라 순서대로 보세요. 각 페이지 아래에 다음 단계가 이어집니다.

경영관리 한 해

계획을 세우고, 예산을 나누고, 매달 손익을 보고, 원가를 관리하고, 성과를 평가하기까지

  1. 계획사업계획 달성 확률
  2. 예산비용예산 증액 우선순위
  3. 월 손익월 손익 보고
  4. 원가원가 행태·불량 관리도
  5. 지표KPI 트리
  6. 평가·보상성과평가 MBO·KPI

투자 한 건

타당성을 따지고, 누가 승인하는지 확인하고, 자금을 마련하고, 집행 뒤 검증하기까지

  1. 타당성설비투자 분석 키트
  2. 승인 권한위임전결 기준 점검
  3. 차입 여력적정 부채·파산 위험

  6. 사후관리투자 사후관리

M&A 거래

절차 전체를 보고, 가격을 따지고, 공개 사례와 지주사 가치로 넓히기까지

  2. 가격M&A 가치평가

  1. 읽는 틀재무제표 분석 프레임워크

  5. 산업 전망AI 인프라 읽기 노트

설비투자 분석 키트

설비투자 타당성(NPV·IRR·회수기간), 가동률과 원가, 계획 대비 실적을 브라우저에서 바로 계산하는 도구

투자·M&A통계·확률 리포트 먼저 볼 것

삼성전자, 메모리 호황의 재무

삼성전자 2025 사업보고서와 2026 반기보고서의 재무제표와 주석을 원문 쪽수와 함께 옮기고 검산해, 메모리 호황이 손익·현금·재무상태표에 남긴 흔적을 분석한 리포트

기업·산업 분석 노트 먼저 볼 것

통계 기법과 활용

기획·분석 실무에서 쓰는 통계 기법 14가지를 직접 계산한 도표, 사용 예시, 함정, 엑셀·R 함수와 함께 정리한 노트

통계·확률보고·시각화 도구

KPI 트리(ROIC 가치동인)

ROIC를 판매량·단가·수율·회전일수 같은 현장 지표까지 수식으로 쪼개고, 계획 대비 차이를 지표·조직별로 샤플리 값으로 나누며 ROIC를 가장 많이 올리는 레버를 찾는 도구

경영관리 도구

사업계획 달성 확률

판매량·단가·환율·원재료가 함께 흔들릴 때 영업이익의 분포, 계획 달성 확률, Earnings-at-Risk와 변동 기여도를 계산하는 도구

경영관리통계·확률 도구

비용예산 증액 우선순위

증액 요청의 효과 범위와 성공 확률로 기대가치를 매기고, 승인 한도 안에서 정수계획으로 최적 조합과 예산의 한계가치를 찾는 도구

경영관리통계·확률 도구

월 손익 보고

SAP 조회 형식 데이터로 당월·누계 손익, 영업이익 차이 분해, 연간 전망을 만드는 월 손익 보고 도구

경영관리통계·확률 도구

원가 행태·불량 관리도

월별 생산량과 제조원가로 고정비·변동비를 회귀 추정하고 구조변화를 검정하며, 불량률을 p 관리도·넬슨 규칙·EWMA로 감시하고 공정 정비 효과를 검정하는 도구

경영관리통계·확률 도구

성과평가 MBO·KPI

KPI 구간 점수, 조직 등급, 인센티브 배분, KPI 설계 점검까지 성과평가 도구

경영관리통계·확률 도구

13주 자금수지·약정

영업일 규칙과 한도대출, 분기말 재무약정까지 반영한 13주 자금수지 도구

경영관리통계·확률 도구

적정 부채와 파산 위험

현금흐름 기반 부도확률, 머튼 부도거리, 사내 기준별 부채 한도, 절세효과와 부실비용의 맞교환으로 적정 부채를 찾는 도구

경영관리투자·M&A통계·확률 도구

위임전결 기준 점검

업무 항목별 결재권자 한도가 이사회규정 부의 기준과 상법상 이사회 결의 사항에 어긋나지 않는지 점검하는 도구

경영관리 도구

투자 사후관리

투자·M&A 도구

M&A 절차 지도

비밀유지계약부터 인수 후 통합까지 M&A 전 과정과 단계별 실무 위치를 정리한 절차 지도

투자·M&A 도구

M&A 가치평가

투자·M&A 도구

환리스크 헤지

투자·M&A 리포트

업종별 재무제표 읽기

업종마다 재무제표의 생김새와 먼저 볼 숫자가 다릅니다. 반도체 소모품·장비, 2차전지, 자동차, 조선, 지주회사, 플랫폼 대표 7개사의 2025 사업보고서·2026 반기보고서를 원문 쪽수와 함께 옮기고 검산해, 듀폰 ROE·운전자본·현금 흐름으로 나란히 읽은 리포트
