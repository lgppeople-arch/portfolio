한 줄에 기간, 사업부, 계정, 계획, 실적 순서입니다. 엑셀에서 복사한 탭 구분 표도 됩니다. 계정은 매출액·재료비·노무비·제조경비·판매관리비를 씁니다. 실적이 아직 없는 달은 비워 두세요.

    같은 예시 데이터를 pandas로 계산해도 이 화면과 같은 숫자가 나오는지 확인했습니다. 전체 코드는 저장소의 examples/pl_report.py에 있습니다.

    def pnl(frame, col):
    """계정별 합계를 손익 항목으로 바꾼다."""
    v = frame.groupby("항목")[col].sum().reindex(KEY.values(), fill_value=0.0)
    cogs = v["mat"] + v["lab"] + v["ovh"]
    op = v["rev"] - cogs - v["sga"]
    return pd.concat([v, pd.Series({"cogs": cogs, "op": op,
                                    "cmr": (v["rev"] - v["mat"]) / v["rev"]})])

def bridge(p, a):
    """영업이익 차이를 매출 증감, 공헌이익률 변화, 고정비 항목으로 나눈다."""
    return pd.Series({
        "매출 증감": (a["rev"] - p["rev"]) * p["cmr"],
        "공헌이익률 변화": (a["cmr"] - p["cmr"]) * a["rev"],
        "노무비": p["lab"] - a["lab"],
        "제조경비": p["ovh"] - a["ovh"],
        "판매관리비": p["sga"] - a["sga"],
    })

# 9월 누계, 전사:  매출 증감 -13.8  공헌이익률 변화 -20.0  노무비 -3.6  제조경비 9.0  판매관리비 0.0

    계산 기준

    • 매출원가 = 재료비 + 노무비 + 제조경비, 영업이익 = 매출 − 매출원가 − 판매관리비. 재료비를 변동비, 나머지를 고정비로 보고 공헌이익률 = (매출 − 재료비) ÷ 매출로 계산합니다.
    • 차이는 실적 − 계획입니다. 매출과 이익은 줄면, 비용은 늘면 불리한 차이로 빨갛게 표시합니다.
    • 영업이익 차이 분해: 매출 증감 효과 = 매출 차이 × 계획 공헌이익률, 공헌이익률 효과 = 공헌이익률 차이 × 실적 매출, 고정비는 항목별 계획 − 실적. 다섯 효과의 합은 영업이익 차이와 정확히 같습니다. 전사로 보면 사업부 구성(믹스) 변화가 매출 증감과 공헌이익률 효과에 섞여, 사업부별 분해의 단순 합과 다를 수 있습니다.
    • 추정: 기준월 다음 3개월에 계획 × 달성률을 계정별로 적용합니다. 누계 달성률은 1월부터 기준월까지, 최근 3개월은 최근 석 달의 실적 ÷ 계획입니다. 그 뒤 달은 계획을 씁니다. 연간 전망 = 누계 실적 + 3개월 추정 + 남은 계획.
