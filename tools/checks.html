계산 검산

이 사이트의 도구는 AI 코딩 도구와 함께 만들었습니다. 그래서 숫자가 맞는지는 따로 확인합니다. 아래 항목은 지금 이 브라우저에서 각 도구의 계산 엔진을 직접 돌려 나온 결과입니다. 읽는 법은 쉬운 가이드에 있습니다.

01

항등식으로 확인

실적이 계획과 같으면 차이가 0이어야 하고, 기여도를 다 더하면 총 차이와 같아야 합니다. 답을 몰라도 틀렸는지는 알 수 있는 검사입니다.

02

기존 계산과 대조

새 도구가 기존 도구의 계산을 다시 쓸 때는 무작위 가정 수백 개를 넣어 두 계산이 같은 값을 내는지 봅니다.

03

실무 규칙을 테스트로

급여일이 휴일이면 앞당기고 세금 기한은 다음 영업일로 미루는 식의 규칙을 실제 날짜로 확인합니다.

같은 검산을 node assets/checks.js로도 돌릴 수 있습니다. 코드는 GitHub 저장소에 있습니다.
